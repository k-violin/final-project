# 와이즈인컴퍼니(WiseIN Company) 기업 웹사이트 구축 계획

밝고 깔끔한 기업형 사이트 + 관리자 CMS를 만듭니다. 확정된 사실만 사용하고, 미확정 정보는 빈 상태로 둡니다.

## 1. 디자인 기반
- 컬러: 딥 네이비 #081A30(히어로), 프라이머리 블루 #1264FF, 시안 #22C8F6, 본문 #263244, 섹션 배경 흰색/#F5F7FA
- 폰트: Pretendard, 굵기는 400 이상만 사용
- 콘텐츠 최대 폭 1,280px, 넉넉한 여백, 과한 라운드·그라데이션·네온 없음
- 은은한 등장/호버 모션만, reduced-motion 지원, 히어로 배경 애니메이션 없음
- 텍스트 로고 "WiseIN Company"(추후 이미지 로고로 교체 가능한 단일 컴포넌트)

## 2. 공통 레이아웃
- 흰색 스티키 헤더 + 내비게이션: Home, Business, Portfolio, Blog, About Us, Support, 강조된 "문의하기" 버튼
- Business / About Us / Support는 키보드 접근 가능한 드롭다운, 현재 페이지 표시
- 모바일: 접근성 있는 메뉴 버튼, 서브메뉴 펼침/접힘, 문의하기 상시 노출
- 푸터: 텍스트 로고, 슬로건, 주요 링크, 문의하기, 개인정보처리방침, 저작권. 주소·전화·이메일은 관리자 설정값이 있을 때만 표시

## 3. 페이지 구성
- **Home**: 히어로(생성한 정적 추상 데이터 네트워크 이미지 + 지정된 헤드라인/서브카피/CTA) → 신뢰 지표 4개(정적 표시) → 사업 개요 4개 카드(데이터 분석·AI 솔루션 강조, 카드 클릭은 해당 Business 페이지, "문의하기"는 분야가 미리 선택된 Contact Us로 이동) → 주요 프로젝트 2건 → Blog 최신 3개(없으면 빈 상태) → 최종 문의 CTA
- **Business**: 데이터 분석 / AI 솔루션 / 플랫폼 서비스(Richway) / 국비교육 프로그램 — 각각 간결한 소개 + 섹션별 문의하기 버튼
- **Portfolio, Blog**: 각각 단일 목록 페이지. 카테고리 필터, 제목·요약 검색, 최신순, 페이지네이션, 로딩/에러/빈 상태. 상세는 같은 페이지의 접근성 있는 패널로 열리며 공유 가능한 주소와 뒤로가기 지원, 목록 복귀 시 필터·스크롤 유지
- **About Us**: 회사개요, 비전과 미션(임시 초안임을 명시, 편집 가능), 회사연혁(2003년 설립 시작), 보도자료, 오시는 길(미설정 안내 상태)
- **Support**: Contact Us(문의 폼), FAQ(아코디언), 공지사항(고정 공지 우선 표시)
- 사용자 친화적 404, 페이지별 title/description, 관리자 페이지 noindex

## 4. 문의 폼
문의 분야(필수)·세부 서비스·회사명·담당자(필수)·이메일(필수, 형식 검증)·연락처·제목(필수)·내용(필수)·개인정보 동의(필수). 다른 페이지에서 넘어오면 분야 미리 선택, 한국어 검증 메시지, 제출 중 표시, 중복 제출 방지, 저장 성공 시에만 성공 메시지, 실패 시 입력 보존 + 재시도

## 5. 백엔드 (Lovable Cloud)
저장 대상: 포트폴리오/블로그 글·카테고리, 보도자료, FAQ, 공지사항, 회사연혁, 문의 내역, 회사 정보, 신뢰 지표. 이미지 업로드용 저장소 포함.
- 방문자는 게시된 글만 읽기 가능, 초안 접근 불가
- 문의 내역은 관리자만 접근 가능
- 관리자 권한은 별도 권한 테이블로 관리(일반 가입으로 권한 획득 불가, 하드코딩 계정 없음)
- 신뢰 지표(23년/2,000+/1,400+/30,000+)는 관리자가 수정 가능한 단일 데이터로 저장

## 6. 관리자 영역 (/admin, 공개 메뉴에 노출 안 함)
로그인 + 권한 확인 후 접근. 포트폴리오·블로그 글/카테고리, 보도자료, FAQ, 공지사항, 연혁 전체 등록·조회·수정·삭제, 초안/게시 전환, 이미지 업로드·미리보기, 폼 검증, 삭제 확인, 작성/수정 시각 기록. 문의 조회 및 상태 변경(신규/확인 중/처리 완료), 회사 연락처·신뢰 지표 편집.

## 7. 콘텐츠 원칙
확정 사실(2003년 설립, 25명, 지정 문구, 프로젝트 2건)만 사용. 수상·인증·성과 수치·연락처·과정 정보는 만들지 않고 빈 상태로 둡니다. 샘플 데이터는 넣지 않거나 비게시 상태로만 둡니다.

## 8. 완료 후
공개 전 준비 항목(로고, 회사 정보, 확정 비전·미션, 연혁, 이미지, 지표 기준, 카테고리, 교육 정보, 개인정보처리방침, 관리자 계정·알림 설정)을 한국어 체크리스트로 보고합니다.

## 작업 순서
1. 백엔드 활성화 및 데이터 구조·권한 설정
2. 디자인 토큰, 헤더/푸터, 히어로 이미지 생성
3. Home → Business → About Us → Support → Portfolio/Blog
4. 관리자 영역
5. 접근성·반응형·SEO 점검 후 체크리스트 보고
